### **Sesi 2: Analisis Fondasi Matematika & Temuan Kritis (09:30 - 11:00)**

**Aktivitas:**
- Analisis mendalam fondasi matematika FCR-RSA
- Review README.md dan laporan_teknis.md
- Identifikasi celah teoretis

**Temuan Kritis #1: Linearitas Enkripsi**
```rust
// encrypt.rs
let prod = (message * e_vec) % q;
let c = (prod + blinding) % q;
```

**Masalah:**
- Fungsi enkripsi **linear terhadap plaintext**: `C = (M × E_vec) + R_blind mod Q`
- Jika attacker tahu **satu blok plaintext**, bisa hitung: `E_vec = (C - R_blind) × M⁻¹ mod Q`
- Setelah `E_vec` diketahui, **semua pesan** dengan kunci itu bisa didekripsi

**Temuan Kritis #2: Blinding Terbuka**
- `R_blind` dikirim sebagai **prefix plaintext** pada ciphertext
- Attacker tahu nilai blinding → linearitas menjadi fatal

**Temuan Kritis #3: Small-Q Brute-Force**
- Q = 10^9+7 (~30 bit) → seed yang dienkripsi hanya 3 byte (24 bit)
- Ruang pencarian: 16.777.216 kemungkinan → bisa di-brute-force dalam hitungan jam

**Rekomendasi Awal:**
- Block-based chunking (upaya pertama menutup dictionary attack)
- Upgrade Q ke 2048-bit minimum

### **Sesi 5: Arsitektur Hybrid KEM + AEAD (14:30 - 16:30)**

**Aktivitas:**
- Desain arsitektur Hybrid KEM (Key Encapsulation Mechanism)
- Implementasi ChaCha20-Poly1305 (AEAD)
- Integrasi HKDF untuk key derivation

**Arsitektur Baru:**
```
1. Generate seed acak (ukuran sesuai kapasitas Q)
2. Enkripsi seed dengan FCR-RSA → Encrypted_Seed
3. Turunkan kunci sesi 256-bit dari seed via HKDF (RFC 5869)
4. Enkripsi data dengan ChaCha20-Poly1305 (AEAD)
5. Format: BLINDING:ES:NONCE:CT (semua Base64)
```

**Implementasi (v0.5.0):**
```rust
// crypto.rs v0.5.0
// 1. Generate kunci sesi acak 256-bit
let mut session_key_bytes = [0u8; 32];
rand::rng().fill_bytes(&mut session_key_bytes);
let session_key = BigInt::from_bytes_be(num_bigint::Sign::Plus, &session_key_bytes);

// 2. Enkripsi kunci sesi dengan FCR-RSA
let encrypted_session_key = encrypt_with_blinding(&session_key, seed, n, &q, &blinding)?;

// 3. Enkripsi data dengan ChaCha20-Poly1305
let cipher = ChaCha20Poly1305::new_from_slice(&session_key_bytes)?;
let ciphertext = cipher.encrypt(nonce, text.as_bytes())?;
```

**Bug v0.5.0:**
- ❌ Dekripsi gagal: `ChaCha20-Poly1305 decrypt error`
- **Penyebab:** Enkripsi kunci sesi 256-bit dengan Q=10^9 → informasi hilang saat modulo

### **Sesi 6: Perbaikan HKDF-Based Key Derivation (16:30 - 17:30)**

**Aktivitas:**
- Identifikasi bug: Q kecil tidak bisa menampung kunci sesi 256-bit
- Implementasi HKDF untuk menurunkan kunci sesi dari seed yang lebih kecil
- Test round-trip

**Implementasi (v0.5.1):**
```rust
// crypto.rs v0.5.1
// 1. Hitung ukuran seed maksimum yang bisa dienkripsi dengan Q
let max_bytes = max_seed_bytes(&q).max(1);  // Untuk Q=10^9, max = 3 byte

// 2. Generate seed acak yang ukurannya sesuai kapasitas Q
let mut seed_bytes = vec![0u8; max_bytes];
rand::rng().fill_bytes(&mut seed_bytes[..]);
let seed_bigint = BigInt::from_bytes_be(num_bigint::Sign::Plus, &seed_bytes);

// 3. Enkripsi seed dengan FCR-RSA
let encrypted_seed = encrypt_with_blinding(&seed_bigint, seed, n, &q, &blinding)?;

// 4. Turunkan kunci sesi 256-bit dari seed menggunakan HKDF
let hk = Hkdf::<Sha256>::new(None, &seed_bytes);
let mut session_key_bytes = [0u8; 32];
hk.expand(b"fcr-rsa-session-key", &mut session_key_bytes)?;

// 5. Enkripsi data dengan ChaCha20-Poly1305
let cipher = ChaCha20Poly1305::new_from_slice(&session_key_bytes)?;
let ciphertext = cipher.encrypt(nonce, text.as_bytes())?;
```

