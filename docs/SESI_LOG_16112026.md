## 🧪 2. KEPUTUSAN TEKNIS & TEMUAN PENTING

### A. Masalah `Modulus Overflow` pada Teks
Saat pertama kali mencoba enkripsi teks "Halo Dunia" (10 byte), hasil dekripsi menjadi karakter "alien". Ini terjadi karena teks 10 byte (72 *quintillion*) jauh lebih besar dari `Q` (1 Miliar), sehingga terpotong oleh modulo.
**Solusi:** Enkripsi per-byte (Block Cipher sederhana). Setiap karakter dienkripsi secara terpisah, lalu digabungkan dengan koma.

### B. `rand 0.10.3` API Changes
Di versi ini, `OsRng` dihapus dan diganti dengan `rand::rng()`. Trait `RngCore` juga berubah. Solusi: Gunakan `rand::rng().fill_bytes()`.

### C. PostgreSQL Password Encoding
Password `Bp2jk@kalteng123` gagal terhubung karena karakter `@` dan `$`. Solusi: Gunakan *percent-encoding* (`%40` untuk `@`) di file `.env`.

### D. Clap Short Flag Conflict
`clap` otomatis mengambil inisial. `--text` dan `--tier` sama-sama mengambil `-t`, menyebabkan *panic*.
**Solusi:** Gunakan `short = 'N'` untuk `name`, `short = 'm'` untuk `message`, `short = 'k'` untuk `keyname`, dll.
