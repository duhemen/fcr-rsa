## ⚠️ Technical Debt / Catatan untuk Besok

### 1. **Observability Gap (Minor)**
- Skor intermediate (40–69) hanya di-`eprintln`, **tidak di-log ke DB** dan **tidak di-expose di response**.
- **Rekomendasi:** Tambah kolom `risk_score` di response `/encrypt` saat suspicious, atau endpoint debug `/admin/last-risk`.
- **Prioritas:** Rendah (tidak mempengaruhi keamanan).

### 2. **Stress/Concurrency Testing (Belum Dilakukan)**
- Belum ada pengujian beban tinggi (1000+ concurrent requests).
- **Rekomendasi:** Tambah kategori F di `test_brutal_suite.py` dengan flag `--stress`.
- **Prioritas:** Sedang (untuk production readiness).

### 3. **Cross-Language Test Vector (Python ↔ Rust via REST API)**
- Sudah ada di level library (`fcr-pyo3`), tapi **belum diuji via REST API**.
- **Rekomendasi:** Buat test vector JSON yang dikirim via HTTP dan divalidasi response-nya.
- **Prioritas:** Rendah.

### 4. **PyO3 Version**
- Masih di v0.20. Upgrade ke v0.22+ direkomendasikan untuk hilangkan `#![allow(non_local_definitions)]`.
- **Prioritas:** Sangat Rendah (kosmetik).

### 5. **`sqlx-postgres` Warning**
- Warning `sqlx-postgres v0.7.4` akan ditolak di versi Rust masa depan.
- **Rekomendasi:** Upgrade ke `sqlx 0.8` di masa depan (hati-hati breaking changes).
- **Prioritas:** Rendah.
